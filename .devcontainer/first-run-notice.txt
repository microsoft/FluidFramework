COPILOT COMMANDS:
  start                  Let an assistant choose the right workflow
  dev                    Launch Copilot CLI configured for FF development
  copilot                Launch Copilot CLI without an FF-specific profile
  oce                    Launch Copilot CLI for on-call engineer workflows

Custom MCP servers:
  See GETTING_STARTED.md for how to launch agents with your own MCP servers.

Other commands:
  pnpm install           Install all dependencies
  pnpm build             Build all packages
  pnpm test              Run tests
  pnpm fluid-build .     Build only the current package and its dependencies
