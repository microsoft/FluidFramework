# @fluidframework/tree-agent-ses

Secure edit execution helpers for the `@fluidframework/tree-agent` package backed by the
[Secure ECMAScript (SES) runtime](https://github.com/endojs/endo/blob/master/packages/ses/README.md).

Tree Agent can execute JavaScript generated by a language model to edit a SharedTree. When no
custom editor is provided, the generated code has access to application globals. This package
provides
[`createSesEditExecutor`](https://fluidframework.com/docs/api/tree-agent-ses/#createseseditexecutor-function),
which instead runs each edit in an SES compartment with a controlled `context` global. Creating the
executor applies realm-wide lockdown and should be done during application initialization.

SES is a defense-in-depth measure, not a complete sandbox. It shares the host process and JavaScript
engine, depends on early lockdown and carefully selected globals, and does not limit execution time
or memory. Higher-risk scenarios should add separately isolated execution with externally enforced
resource limits.

## Installation

```bash
npm install @fluidframework/tree-agent-ses
```

## Usage

```typescript
import { createSesEditExecutor } from "@fluidframework/tree-agent-ses/alpha";
import { executeSemanticEditing } from "@fluidframework/tree-agent/alpha";

const editor = createSesEditExecutor();
await executeSemanticEditing(model, tree, prompt, { editor });
```

The returned callback can be provided as the `editor` option to
[`createTreeAgent`](https://fluidframework.com/docs/api/tree-agent/#createtreeagent-function) or
[`executeSemanticEditing`](https://fluidframework.com/docs/api/tree-agent/#executesemanticediting-function)
from `@fluidframework/tree-agent`.
