# Examples

These runnable packages demonstrate supported end-to-end compositions.

- [`sea-counter/`](sea-counter/) demonstrates snapshot recovery and replay over the native client and in-memory storage.
- [`fluid-native-service-example/`](fluid-native-service-example/) demonstrates native service assembly and process lifecycle behavior.

Each example README lists its command, expected behavior, and limitations. The canonical example gate is documented in [`../DEVELOPMENT.md`](../DEVELOPMENT.md).
