## Agentic Development Findings

Non-overlapping crate ownership allowed parallel inspection and most localized repairs without conflicts.
Core contracts and shared browser fixtures still required coordinator-owned semantic decisions and handoffs.
Unlike iteration 0017, delegates could discover and invoke assigned process tasks in this environment; that does not establish a general terminal fix or cancellation isolation.
The coordinator retained shell, commit, integration, and final validation ownership.
Actual Git objects and machine result provenance were inspected before acceptance.
The owner-local requirement produced useful counterfactual checks: permissive dependent components prevented lower layers from masking missing core validation, while allocation-owner observations tested backing retention rather than payload length.
Broad generated/browser checks remained necessary for distinct runtime boundaries.
Human intervention was limited to the approved run configuration and five recorded semantic/design choices.

## Practices to Keep, Change, or Stop

- Keep exact contract/decision/test rows, report failed attempts, and require fresh generated consumers and independent complete-diff evidence. Owner: coordinator and workstream owners.
- Keep output isolation for worktree-specific negative controls and explicit build/launch target agreement. Owner: execution coordinator and harness owner.
- Change local dispatch practice to narrowly bounded liveness mutations and a single frozen shared-fixture handoff. Owner: coordinator.
- Stop treating clean editor diagnostics, cached build state, test counts, or a passing retry as proof of the requested behavior. Owner: every contributor.
- Do not add a new skill or broaden the audit into redesign or performance qualification merely to absorb deferred findings.
