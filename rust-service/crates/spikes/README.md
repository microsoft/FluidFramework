# Spikes

This folder contains bounded research implementations used to test design questions. Spike code is not a production-readiness claim.

- [`snapshotted-stream-durable-log-spike/`](snapshotted-stream-durable-log-spike/) explores checksummed append and snapshot persistence, crash recovery, and persisted-size behavior.

Each spike README records its guarantees, limitations, and validation commands. Results should be promoted into production crates only through an explicit reviewed decision.
